Programa desenvolvido em Python para a atividade da Agenda 6 de Desenvolvimento de Sistemas.

## 📌 O que o programa faz

O programa pede o valor total de uma compra e calcula automaticamente o desconto correspondente. Depois, mostra o valor do desconto e quanto o cliente deverá pagar.

## 💰 Regras de desconto

🔹 Valor da compra menor que R$ 200,00: desconto de 5%.

🔹 Valor da compra a partir de R$ 200,00 e menor que R$ 300,00: desconto de 10%.

🔹 Valor da compra a partir de R$ 300,00: desconto de 15%.

## ▶️ Como executar

1. Instale o Python 3.
2. Baixe o arquivo `RodrigoNunesSegobia_Ag6_DS_I.py`.
3. Abra o terminal na pasta do arquivo.
4. Execute o comando abaixo:

```bash
python RodrigoNunesSegobia_Ag6_DS_I.py
```

## 🧪 Exemplo de execução

```text
Digite o valor total da compra: R$ 250

Valor da compra: R$ 250.00
Desconto aplicado: 10%
Valor do desconto: R$ 25.00
Valor final a pagar: R$ 225.00
```
